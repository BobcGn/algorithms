## 实验 1：算法基础与字符串匹配

实验笔记：[BF 字符串匹配](<Algorithm Design and Analysis/experiences/01_basics/notes/bf.ipynb>)。

笔记使用 **Jupyter Notebook + C 内核**，包含：

- BF（朴素）字符串匹配算法的伪代码与 C 实现。
- 查找结果的文字输出与字符比较次数统计。
- 使用 `clock()` 重复调用算法，统计总 CPU 时间和平均调用 CPU 时间。
- 完全匹配、末尾匹配、模式串更长、空模式串和空主串等边界测试。
- 复杂度分析与实验结论。

打开笔记前，需要安装 Jupyter 及支持 C 语言的内核。选择 C 内核后，按顺序执行代码单元格；修改输入后，应重新执行相关单元格，使保存的输出与代码一致。

## 分析与记录约定

设主串长度为 `n`、模式串长度为 `m`，当 `1 ≤ m ≤ n` 时，BF 算法最坏字符比较次数为 `(n - m + 1) × m`，一般最坏时间复杂度上界为 `O(nm)`，辅助空间复杂度为 `O(1)`。

复杂度分析应区分匹配操作与完整实现中的长度计算等开销。运行记录应注明输入规模、比较次数、重复次数和时间单位。CPU 时间是当前环境下的测量结果，不能单独作为复杂度的证明。
